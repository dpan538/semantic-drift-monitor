# Semantic Drift Monitor

**A computational pipeline to detect when promotional language erodes commodity potential**

This repository implements the research design proposed in *"Commercial Semantic Drift and Commodity Potential Attenuation"*. It provides:

- Longitudinal collection of product pages, reviews, and creator content
- Operational indicators for overload, mismatch, fatigue, devaluation, and lock-in
- Automated drift detection and alerting (email + log)
- Evaluation framework with human annotation and permutation tests

**Primary use case**: Skincare and sunscreen products (easily adaptable to other categories).

**Key constructs**:

- Semantic gap (promo vs. consumer language)
- Skepticism ratio and keyword sentiment drift
- Scenario entropy decline (use-case narrowing)
- Composite attenuation index

**Data sources** (examples): Amazon Product API, static snapshots, public datasets, or any e-commerce platform with reviews.

**Outputs**: Time-series metrics, drift alerts, and evaluation reports.

## Research Motivation

Promotional language does not simply describe commodities. It builds expectations, assigns symbolic value, and frames how consumers interpret product performance. In platformized commerce, that meaning is produced by brands, retailers, platform tags, recommendation systems, and creator endorsements at the same time.

The core hypothesis of this project is that repeated promotional meaning can become commercially counterproductive. A product may continue to sell while its future commercial potential weakens: consumers may become less trusting, less clear about the product's real function, less willing to repurchase, more skeptical of its price, or more likely to see it as useful only in a narrow context.

This repository turns that hypothesis into a reproducible computational workflow.

## Core Concepts

**Commercial semantic drift** is defined here as a measurable divergence between the meaning structure generated by promotional texts and the meaning structure expressed in consumer responses over time.

**Commodity potential attenuation** is treated as a multi-dimensional outcome, not a single sales metric. The first-stage measurable dimensions are:

- Trust erosion
- Clarity loss
- Usefulness mismatch
- Value-for-money skepticism
- Repeat-purchase weakness
- Use-case narrowing

The project deliberately distinguishes current sales from latent commercial potential. Sales can remain stable while trust, clarity, repeatability, or extensibility decline.

## Pilot Study

The first pilot focuses on sunscreen and SPF skincare products, especially claims around:

- `natural`
- `clean`
- `gentle`
- `sensitive skin`
- `dermatologist tested`
- `reef safe`
- `non-greasy`
- `invisible`
- `no white cast`

This category is useful because it has dense promotional language, abundant consumer reviews, clear functional expectations, and observable claim-experience gaps such as irritation, white cast, greasiness, makeup pilling, and sunburn complaints.

## Quick Start

```bash
git clone https://github.com/dpan538/semantic-drift-monitor.git
cd semantic-drift-monitor
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python3 run_pipeline.py --demo
```

The demo run reads the sample files in `examples/` and writes a product-month panel plus alert log to `outputs/`.

## Using Real Data

Create or import three files:

```text
data/raw/products.csv
data/raw/snapshots.csv
data/raw/reviews.csv
```

Then run:

```bash
python3 run_pipeline.py \
  --products data/raw/products.csv \
  --snapshots data/raw/snapshots.csv \
  --reviews data/raw/reviews.csv
```

Recommended columns are documented in [docs/data_schema.md](docs/data_schema.md).

## Main Indicators

The current pipeline computes:

- Promotional keyword density
- Natural/clean claim density
- Clinical/premium claim density
- Abstractness ratio
- Coarse semantic gap between promotional and review language
- Skepticism ratio
- Value complaint ratio
- Negative repurchase ratio
- Scenario entropy
- Lock-in risk
- Exploratory attenuation index

See [docs/indicators.md](docs/indicators.md) for definitions and formulas.

## Research Workflow

1. Build a product master table.
2. Import or collect product-page snapshots.
3. Import or collect timestamped reviews.
4. Clean and segment text.
5. Extract promotional terms, claims, skepticism markers, value complaints, and scenarios.
6. Aggregate metrics into a product-month panel.
7. Validate lexical flags against human annotations.
8. Run fixed-effects models or event studies.
9. Export figures, tables, and reproducible analysis notes.
