# Journal of Marketing Analytics Submission Requirements

Source: Journal of Marketing Analytics submission guidelines, Springer Nature.  
URL: https://link.springer.com/journal/41270/submission-guidelines

## Review Model

The journal uses **double-blind peer review**.

Implication:

- The main article file must not contain author names, affiliations, acknowledgements, repository ownership statements, or self-identifying phrasing.
- The author information file is separate.
- If code/data repository links are included during review, they should be anonymized where necessary or provided only after review if the submission system permits.

## Minimum Submission Files

At minimum:

1. Author information file.
2. Main article file.

Optional:

- cover letter;
- separate figures/tables document;
- supplementary/appendix files.

## Author Information File

The author information file should include:

- full article title;
- short running title of no more than 45 characters including spaces;
- author names and affiliations;
- short biography of no more than 100 words for each author;
- corresponding author contact details, including email;
- word count for the entire submission, including abstract, notes, references, and acknowledgements.

## Anonymous Article File

The article file should include:

- title;
- unstructured abstract of no more than 200 words;
- 3-6 keywords/phrases;
- full article text;
- references;
- tables/figures either within the file after first mention or uploaded separately.

The article file must not contain identifying author information.

## Abstract and Keywords

Abstract:

- unstructured;
- no more than 200 words;
- direct and reader-friendly.

Keywords:

- 3-6 terms or phrases;
- should support indexing and web search.

Recommended keywords:

- marketing analytics;
- online reviews;
- semantic gap;
- sunscreen;
- consumer skepticism;
- scenario lock-in.

## References

The journal uses **Harvard author-date** style.

Working implications:

- In-text citations should use author-date form, for example `(Wedel and Kannan, 2016)`.
- For three or more authors, use first author followed by *et al*.
- Reference list should be alphabetical by author surname.

## Tables and Figures

Important requirements:

- Every table and figure should be referred to in the text.
- Legends should be short and descriptive.
- The journal prints in black and white; figures should not rely on colour alone.
- Prefer greyscale-safe lines, markers, and labels.
