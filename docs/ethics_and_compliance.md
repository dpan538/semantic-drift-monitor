# Ethics and Compliance

This repository is intended for academic research and education.

Before collecting platform data, researchers must review:

- the target site's Terms of Service
- `robots.txt`
- API documentation
- privacy and data protection rules
- rules governing user reviews, endorsements, and sponsored content

Recommended data sources:

- official product or advertising APIs
- licensed datasets
- static snapshots collected with permission
- public research datasets
- manually exported data where allowed

This repository does not provide code for bypassing CAPTCHAs, login walls, access controls, anti-bot systems, or rate limits.

## Review Data

Review text can contain personal details. Store only what is necessary for the research question. Avoid collecting usernames, profile URLs, location, photos, or other identifiable metadata unless the research protocol explicitly requires it and the data source permits it.

## Reproducibility

For public release, prefer:

- de-identified review IDs
- product IDs that can be mapped through a controlled appendix
- snapshots with timestamps
- clear collection logs
- data dictionaries
- annotation codebooks

## Platformized Influence

Creator content and sponsored posts may be governed by endorsement disclosure rules. Preserve visible disclosure markers where allowed, but avoid collecting private account information.
